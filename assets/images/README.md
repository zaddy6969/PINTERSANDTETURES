# Website images

Upload website image assets to this folder.

## How to add an image
1. Open the `assets/images` folder in this repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload the image (for example, `pt-logo.jpg`) and commit the change to `main`.

## Logo
The Painters & Textures logo should be saved as `assets/images/pt-logo.jpg`.
Once uploaded, the site can reference it as `/assets/images/pt-logo.jpg`.

Keep image filenames lowercase and use hyphens instead of spaces.
